Simulador de aceleración y movimiento de un automóvil

Descripción

Este proyecto consiste en una aplicación desarrollada en Python que permite simular el movimiento de un automóvil mediante las ecuaciones de Movimiento Rectilíneo Uniformemente Acelerado (MRUA).

El programa permite calcular la velocidad final, la distancia recorrida, el tiempo necesario para alcanzar una velocidad determinada y la distancia necesaria para llegar a ella.

Objetivo

Aplicar los conocimientos de física y programación para desarrollar una herramienta que permita realizar cálculos relacionados con la aceleración de un automóvil.

Tecnologías utilizadas

Python.

Visual Studio Code.

GitHub Copilot.

Git y GitHub.

Estructura del proyecto

main.py: archivo principal que contiene el menú.

clases/automovil.py: almacena los datos del automóvil.

clases/simulador_movimiento.py: realiza los cálculos de MRUA.

especificaciones/: contiene las especificaciones de las clases y del programa principal.

documentacion/: contiene el análisis del problema, las pruebas y el uso de Copilot.

evidencias/: contiene las imágenes del problema original y las capturas de ejecución.

Requisitos

Tener Python instalado.

Contar con Visual Studio Code o una terminal para ejecutar el programa.

Cómo ejecutar el programa

Descargar o clonar el repositorio.

Abrir la carpeta del proyecto.

Abrir una terminal.

Ejecutar el siguiente comando:

python main.py

Funcionamiento

El usuario puede registrar un automóvil, ingresar su velocidad inicial y aceleración, realizar los cálculos disponibles y consultar el historial de simulaciones.
